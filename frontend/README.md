# Frontend

React + Vite frontend untuk aplikasi booking driver dan travel request.

## Environment

Buat file `frontend/.env`:

```bash
VITE_API_BASE_URL=http://localhost:8000
```

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Frontend ini memakai API backend FastAPI yang sekarang menyimpan data ke MongoDB.
