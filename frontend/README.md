# Frontend

React + Vite frontend untuk aplikasi booking driver dan travel request.

## Environment

Gunakan `.env.development` di root project. Vite sudah dikonfigurasi untuk membaca file tersebut.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Frontend ini memakai API backend FastAPI yang sekarang menyimpan data ke MongoDB.
